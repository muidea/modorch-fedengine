# 原生数据库组织契约

## FE-ORG-001

触发：实例发现、逐原生数据库登记、激活及虚拟库发布。
保证：PostgreSQL 与 MySQL 均按产品、规范化实例身份及原生数据库精确名称分组，每个原生数据库对应一个自动虚拟库。同一连接登记可发现多个数据库，并逐库命名；同原生库的不同登记必须复用已有名称并合并贡献。不同端口、产品或原生库不得因同名而合并，凭据和登记别名不参与原生身份。PG 保留来源 Schema，MySQL 保留源 database 同名 Schema；重叠贡献共享目录身份，移除一个贡献不移除其他贡献和远端对象。
边界：自动组织不创建跨原生库的汇总业务库，不推断 DNS 或代理身份。发现与登记不等于激活成功；失败目标保留状态，不发布伪成功目录。显式实例身份、授权、资源排空与重启身份规则见[组织说明](../docs/source-database-organization-plan.md)。
